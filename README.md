# LeadFinder AI - AI-Powered Lead Generation Tool

Find businesses without websites. Generate AI-powered outreach. Close more deals.

## Features
- Smart business search
- AI-powered website analysis
- Personalized email & WhatsApp outreach
- Google OAuth authentication
- Dashboard with analytics

## Tech Stack
- Next.js 16, TypeScript, Tailwind CSS, Prisma, NextAuth.js

## Getting Started
1. Clone the repo: git clone https://github.com/deepakrai9813/leadfinder-ai.git
2. Install: npm install
3. Set up .env from .env.example
4. Run: npx prisma generate && npx prisma db push
5. Start: npm run dev
